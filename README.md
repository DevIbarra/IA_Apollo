# Apollo AI Agent 🤖

Apollo é um agente inteligente desenvolvido em **Python** que utiliza **LLMs, RAG e banco de dados** para interpretar comandos em linguagem natural e executar ações dentro do sistema.

O projeto explora a construção de **AI Agents capazes de compreender solicitações do usuário, recuperar contexto relevante e executar operações automaticamente**.

---

# 🚀 Funcionalidades

- Interpretação de linguagem natural com LLM
- Recuperação de contexto utilizando **RAG (Retrieval Augmented Generation)**
- Memória de conversa para manter contexto
- Integração com banco de dados **PostgreSQL**

---

↓

- Python
